How to Run
1. Extract the project ZIP file (if downloaded as a ZIP).
2. Open the Bean-Corner folder.
3. Open index.html in any modern web browser.
Project Structure
- index.html – Contains the page structure and content.
- style.css – Contains all styles, colors, and responsive design.
- script.js – Handles the mobile navigation menu and simple interactions.
- images/ – A dedicated folder for local images, where you can replace the existing images if needed.
Technologies Used
- HTML5
- CSS3
- Vanilla JavaScript
